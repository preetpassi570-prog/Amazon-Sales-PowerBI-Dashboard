# 🛒 Amazon Global Sales & Customer Insights - Power BI Dashboard

## 📝 Project Overview

This project is an end-to-end Power BI dashboard designed to analyze the sales performance, customer demographics, and product trends for an **Amazon retail dataset** (specializing in bikes, sporting clothing, and outdoor accessories).

The goal of this dashboard is to transform raw Amazon sales data into actionable insights, helping stakeholders track KPIs, understand regional performance across different Amazon marketplaces, and identify the most valuable customers and top-performing products.

## 🚀 Key Highlights & Metrics

* **Total Revenue:** \$24.9M
* **Total Orders:** 56K
* **Total Profit:** \$10.5M
* **Return Rate:** 2.2%

## 📂 Dashboard Pages & Features

The dashboard is divided into four main interactive views:

### 1. Executive Dashboard
Provides a high-level overview of the Amazon business's health.
* Tracks main KPIs (Revenue, Orders, Profit, Return %).
* Displays monthly revenue trends (Jan 2020 - Jan 2023).
* Highlights the **Top 10 Amazon Products** by revenue, orders, and profit.
* Categorizes orders by product type (Accessories, Bikes, Clothing).

### 2. Map Dashboard
Visualizes geographical sales distribution across global Amazon marketplaces.
* Interactive map showing orders by country across Europe, North America, and the Pacific.
* Allows filtering by specific regions to see localized performance and shipping hotspots.

### 3. Product Dashboard
A deep dive into individual product performance against set Amazon sales targets.
* Users can select specific products (e.g., Road Tire Tube) to see dedicated metrics.
* Compares Monthly Orders, Revenue, and Profit against target goals using gauge charts.
* Includes a trending metrics chart to monitor profit and return percentages over time.

### 4. Customer Dashboard
Focuses on buyer demographics and Amazon prime/regular customer purchasing behavior.
* **Unique Customers:** 17.4K | **Revenue Per Customer:** \$1,431
* Breaks down orders by **Income Level** (High, Low, Average) and **Occupation** (Clerical, Skilled Manual, Professional).
* Identifies the Top 100 Customers and highlights the highest-spending individuals (e.g., Mr. Maurice Shan).

## 🛠️ Tools & Technologies Used

* **Power BI:** Data visualization, DAX measures, Data modeling, and interactive reporting.
* **Data Source:** Raw Amazon sales, product catalog, and customer datasets (Excel/CSV).

## 💡 Key Insights Derived

1. **Top Products:** The "Water Bottle - 30 oz." and "Sport-100 Helmets" are major revenue drivers in the catalog.
2. **Customer Base:** The majority of Amazon orders come from customers with an "Average" income level and those working in "Professional" or "Skilled Manual" occupations.
3. **Returns:** Tires and Tubes have the highest return rate, which might indicate a need for quality checks with the supplier or updating the Amazon product listing descriptions.

## 🤝 How to Use

1. Clone this repository to your local machine.
2. Open the `.pbix` file using Power BI Desktop.
3. You can interact with the filters, slicers, and map visuals to explore the Amazon sales data dynamically.
